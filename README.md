# Лабораторна робота №2: Custom Data Structures & Cache Implementation

Проєкт містить власні реалізації базових структур даних та кешу на мові Java без використання стандартних колекцій `java.util.*` (за винятком служебних методів роботи з масивами).

---

## Основний функціонал
1. **Custom Lists (`MyList`):**
   * `MyArrayList`: Динамічний масив із підтримкою маркерного інтерфейсу `RandomAccess`.
   * `MyLinkedList`: Двозв'язний список із двосторонньою навігацією та оптимізованим пошуком елементів.
2. **`MyLinkedHashSet`:**
   * Реалізація структури даних на основі хеш-таблиці та двозв'язного списку для забезпечення унікальності елементів та збереження порядку їх додавання.
3. **`MyCache`:**
   * Реалізація кешу з підтримкою:
     * **Strict Null Policy:** Заборона збереження `null` ключів та значень (`NullPointerException`).
     * **LRU Eviction Policy:** Витіснення найменш використовуваних записів при досягненні ліміту ємності (`maxCapacity`).
     * **TTL Expiry:** Автоматичне анулювання та видалення елементів за вичерпанням терміну придатності.

---

```text
